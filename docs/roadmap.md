# GhostLink — Roadmap & Milestone Plan

## Milestone Tracking

| Milestone | Status | Description |
|---|---|---|
| **Milestone 1 — Foundation** | **DONE** | Inspect workspace, choose stack, establish unified transfer model, verify build and automated test suites (204 tests passing). |
| **Milestone 2 — Nearby Discovery** | **IN PROGRESS** | Local device discovery via UDP broadcast/multicast and local subnet scanner; device announcements, presence heartbeat, disappearance detection. |
| **Milestone 3 — Nearby File Transfer** | **NEXT** | Direct LAN streaming transfer with peer approval modal, live progress/speed/ETA, SHA-256 verification, and 100% offline support. |
| **Milestone 4 — Material 3 Integration** | Scheduled | Complete Material Design 3 adaptive UI with Home, Nearby, Anywhere, Transfers, and Settings views. |
| **Milestone 5 — Remote Pairing** | Scheduled | WebRTC signaling with short 6-character pairing codes, QR codes, and expiring sessions. |
| **Milestone 6 — Remote File Transfer** | Scheduled | End-to-end encrypted transfer over WebRTC DataChannels across different networks with STUN/TURN traversal. |
| **Milestone 7 — Reliability** | Scheduled | Chunked resume from IndexedDB checkpoints, SHA-256 hash validation, sliding-window flow control. |
| **Milestone 8 — Production Readiness** | Scheduled | Cross-platform optimizations, packaging scripts, security hardening. |
